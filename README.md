# Fuel Tracker

## Розробка

Редагуй файли в `src/`, а не кореневий `index.html`. Потім виконай:

```sh
node scripts/build.mjs
```

Якщо у тебе встановлений npm, також працює `npm run build`.

Скрипт збере один `index.html` для GitHub Pages та створить `sw.js` з новою версією офлайн-кешу.
